# Windows Game Explorer Manager and Helper
Despite the name, this tool currently doesn't do much besides let you (re)install the Games Explorer that was pushed with Windows Vista and Windows 7, and remained bundled with Windows 8; Windows 8.1; and Windows 10, version 1709 and earlier. It automatically downloads everything necessary if you're online - or you can supply your own files for a fully offline installation if you'd rather:
* `__7zr.exe` - https://7-zip.org/a/7zr.exe *OR* a valid copy of 7-Zip installed
* `__ResourceHacker.exe` - https://www.angusj.com/resourcehacker/resource_hacker.zip - inside of ZIP file

I want it to eventually at the very least help you download and install the games that came preinstalled with Windows Vista and Windows 7. Even better, perhaps I could automatically import games from other launchers
